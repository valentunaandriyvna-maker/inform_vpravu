                        1
                        
Створення та налаштування вікна

                    

                    

                        Для роботи з графічним інтерфейсом підключають модуль tkinter та створюють головне вікно.
                    

                    
from tkinter import *

root = Tk()                  # створення вікна
root.title("Назва вікна")   # заголовок вікна
root.geometry("400x300")     # ширина x висота
root.configure(bg="skyblue") # колір фону форми

root.mainloop()              # запуск циклу подій

                


                
                

                    

                        2
                        
Текстовий напис — Label

                    

                    

                        Віджет Label виводить статичний текст у вікні. Щоб елемент з'явився на формі, використовують метод .pack() або .place().
                    

                    
lbl = Label(
    root,                    # батьківське вікно
    text="Привіт, світ!",    # текст напису
    fg="darkblue",           # колір літер (foreground)
    bg="lightyellow",        # колір фону напису
    font=("Arial", 16)       # шрифт і розмір
)
lbl.pack(pady=10)            # розміщення у вікні

                


                
                

                    

                        3
                        
Кнопка — Button

                    

                    

                        Віджет Button створює кнопку. Атрибут command вказує ім'я функції (без дужок!), яка виконається при натисканні.
                    

                    
def say_hi():
    lbl.configure(text="Кнопку натиснуто!")

btn = Button(
    root,
    text="Натисни",          # напис на кнопці
    bg="green",              # колір фону кнопки
    fg="white",              # колір тексту кнопки
    width=15,                # ширина в символах
    command=say_hi           # функція при кліку
)
btn.pack()

                


                
                

                    

                        4
                        
Важливі параметри та часті помилки

                    

                    
    
                        
  • 
                            Розміри вікна: у geometry("500x350") пишеться латинська літера x (а не зірочка *), і значення береться в лапки!
                        
    • 
                        
  • 
                            Кольори: можна вказувати англійською назвою ("red", "yellow", "lightblue") або HEX-кодом ("#FF5733").
                        
    • 
                        
  • 
                            bg та fg: bg (background) — колір фону, fg (foreground) — колір тексту.
                        
    • 
                        
  • 
                            Невидимі віджети: якщо створити Label або Button, але забути викликати .pack() або .place(), віджет не з'явиться у вікні!
